    Settings

    Rules applied to every file
    • Bitrate is never raised. A file already at or below the chosen bitrate keeps its own bitrate; the other settings still apply.
    • Nothing is upsampled, and a mono file stays mono.
    • Files that wouldn't get smaller are skipped, as are files where no setting would change anything.
    • Tags and cover art are kept, copied byte for byte.
    • Every new file is decoded end to end and checked, then written and read back, before an original is touched. Originals are never overwritten.
    • In VBR mode a bitrate is a target mapped to a LAME quality level (V0–V9), so actual size depends on the audio.
